Desenvolvedor de Software com experiência prática na construção de **sistemas internos, aplicações web e mobile, APIs e automações de processos**.

Atualmente, atuo como **Estagiário de Desenvolvimento de Software e IA**, desenvolvendo soluções para problemas reais de negócio, desde o **levantamento de requisitos e modelagem da solução até desenvolvimento, integração e deploy**.
